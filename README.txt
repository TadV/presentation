МАФИЯ — ПРЕЗЕНТАЦИЯ

ЗАПУСК
Откройте index.html в браузере. Сборка, установка библиотек и интернет
для работы сайта не нужны. Для размещения на любом статическом хостинге
скопируйте index.html, style.css, script.js, slides.js и папку slides.
Папка images содержит неизменённые оригиналы и сайтом не используется.

УПРАВЛЕНИЕ
Кнопки ‹ и ›, стрелки клавиатуры, Page Up / Page Down, пробел — листание.
Home / End — первый / последний слайд. Листание по кругу.
На сенсорном экране — свайп вдоль презентации.
«Повернуть» или R — поворот всей презентации с управлением на 90 градусов.
Повторное нажатие возвращает исходную ориентацию. После поворота свайп
также следует направлению презентации.
«Весь экран» или F — полноэкранный режим, если браузер его поддерживает.
Esc отменяет поворот; выход из полноэкранного режима обрабатывает браузер.
Панель скрывается через 3,2 секунды. Касание, движение мыши или Tab
показывают её снова. При управлении с клавиатуры фокус остаётся видимым.
Ссылка вида index.html#slide-3 открывает третий слайд.

ИЗОБРАЖЕНИЯ
Все шесть слайдов сохранены в исходном разрешении 1672 x 941.
WebP — lossless, PNG — без уменьшения палитры или разрешения.
Каждый выходной файл проверен: RGBA-пиксели полностью совпадают с исходником.
Исходники: 12 615 626 байт.
WebP:       9 393 588 байт (меньше на 25,54%).
PNG:       12 047 843 байта (меньше на 4,50%).
Браузер выбирает поддерживаемый формат; при ошибке WebP загружается PNG.
Заранее загружается только следующий слайд.
Изображения показываются целиком, без обрезки или искажения. При другом
соотношении сторон экрана остаются тёмные поля.

ИЗМЕНЕНИЕ ПРЕЗЕНТАЦИИ
Порядок, пути, размеры и подписи находятся в slides.js.
Для нового слайда достаточно PNG; поле webp можно не указывать.
Укажите фактическую ширину и высоту изображения. Счётчик пересчитывается
автоматически. Браузер не сканирует локальную папку: новые слайды нужно
добавлять в slides.js вручную.

СОВМЕСТИМОСТЬ И ПРОВЕРКА
JavaScript написан в синтаксисе ES5, без модулей, fetch и зависимостей.
Разметка не требует Flexbox, Grid, object-fit или CSS-переменных.
Поворот использует CSS transforms, в том числе префиксы WebKit и MS.
Ориентир — IE9+ и старые браузеры с JavaScript и CSS transforms;
реальные устаревшие браузеры в этой среде не тестировались.
Полноэкранный API доступен не во всех браузерах, особенно на iPhone.
Если он недоступен, презентация продолжает занимать всю область страницы.
Поворот работает независимо от Fullscreen и Screen Orientation API.

Проверено в доступном браузере через локальный HTTP-сервер:
отображение, листание, ссылки на слайд, полноэкранный режим и поворот
в размере экрана 390 x 844. Логика свайпов, переход через край, быстрые
переключения и отсутствие Fullscreen API дополнительно проверены
программно. Физические мобильные устройства не тестировались.
Инструмент предпросмотра блокирует file://, поэтому запуск двойным
щелчком не проверен в браузере; код использует обычные относительные
пути и не требует сетевых API или сервера.
